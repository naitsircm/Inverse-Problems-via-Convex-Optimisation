# Inverse-Problems-via-Convex-Optimisation


# Image Deblurring with Optimization

This project formulates image deblurring as a regularized inverse problem, using a DCT-based Gaussian blur operator and total-variation regularization to recover an image from blurred, noisy data.

I implemented and compared ADMM and Primal–Dual optimization, including variable splitting, soft-thresholding, finite-difference operators, and their adjoints. I also tuned algorithm parameters and evaluated reconstructions using mean squared error.
